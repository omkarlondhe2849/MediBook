MediBook is a full-stack web application that transforms the healthcare booking experience. Built with a Spring Boot backend and React frontend, it provides a seamless platform for patients, doctors, and admins.

---

### ✨ Interactive Features Tour
*Click on any feature below to expand!*

<details>
<summary><b>🔐 Authentication & User Management</b></summary>

- **JWT-based Authentication** - Secure login and registration.
- **User Profiles** - Customized dashboards for different roles.
- **Session Management** - Persistent authentication.
</details>

<details>
<summary><b>🎯 Core Functionality</b></summary>

- **Smart Doctor Search** - Find specialists by category, location, or name.
- **Real-time Availability** - View doctor schedules and book instant appointments.
- **Doctor Dashboard** - Manage slots, view bookings, and set vacation days.
</details>

<details>
<summary><b>🤖 Gemini Copilot Assistant</b></summary>

MediBook integrates **Google Gemini 2.0 Flash** to assist users by:
- Navigating the platform.
- Understanding medical terms (informational only).
- Explaining appointment procedures.
</details>
